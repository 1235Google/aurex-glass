# Aurex Glass

A premium glassmorphism Chrome extension that transforms your browser experience.

## Features

- Glassmorphism new tab page
- Chrome UI customization
- Beautiful themes
- Wallpaper customization
- Modern browser dashboard
- Manifest V3 extension

## Installation

1. Download Aurex Glass
2. Open chrome://extensions
3. Enable Developer Mode
4. Load unpacked extension

## Tech Stack

- JavaScript
- HTML
- CSS
- Chrome Extension Manifest V3
